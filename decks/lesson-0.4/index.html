Part 3 · SceneDelegate

A UIKit SceneDelegate

SceneDelegate.swift
import UIKit

class SceneDelegate: UIResponder, UIWindowSceneDelegate {

    var window: UIWindow?

    func sceneDidBecomeActive(_ scene: UIScene) {
        print("Scene became active")
    }

    func sceneWillResignActive(_ scene: UIScene) {
        print("Scene becoming inactive")
    }

    func sceneDidEnterBackground(_ scene: UIScene) {
        print("Scene entered background")
    }
}
1sceneDidBecomeActivethe scene is ready for interaction
2sceneWillResignActivethe scene is about to become inactive
3sceneDidEnterBackgroundthe scene is no longer visible

Scene callbacks only, not the complete configuration a UIKit scene-based project needs.

SAY

Each callback is about one scene, not the whole app: it became active, it is about to resign active, it entered the background. The window property belongs to that scene.

SAY

This shows the callbacks, not the complete configuration a traditional UIKit scene-based project requires.

Part 4 · scenePhase

Observing scene changes

ContentView.swift
import SwiftUI

struct ContentView: View {

    @Environment(\.scenePhase)
    private var scenePhase

    var body: some View {
        Text("NPay Dashboard")
            .onChange(of: scenePhase) { oldPhase, newPhase in
                switch newPhase {
                case .active:
                    print("Active")

                case .inactive:
                    print("Inactive")

                case .background:
                    print("Background")

                @unknown default:
                    break
                }
            }
    }
}
1Read scenePhasefrom the environment
2onChangeruns when the phase changes
3Switch on the phase.active, .inactive, .background
The scenePhase environment value lets SwiftUI code respond to scene lifecycle changes.
SAY

The view reads scenePhase from the environment and reacts with onChange. Each case maps to a scene state from Lesson 0.3. @unknown default keeps the switch safe if Apple adds a phase.

Part 5 · Comparison

UIKit delegates vs SwiftUI lifecycle

ResponsibilityUIKit delegatesSwiftUI lifecycle
App entryAppDelegate-based entry@main App
UI creationUIKit window and view controllersWindowGroup and Views
Scene eventsSceneDelegate callbacksscenePhase
UI layoutAuto Layout, frames, constraintsDeclarative layout
NavigationUINavigationControllerNavigationStack
State updatesExplicit updates, observationState-driven view updates
AppDelegate and SceneDelegate are lifecycle integration mechanisms; SwiftUI is also a complete UI framework. Useful to compare, but not direct replacements for every UIKit feature.
SAY

Six responsibilities. App entry: AppDelegate-based entry versus an @main App. UI creation: windows and view controllers versus WindowGroup and Views. Scene events: SceneDelegate callbacks versus scenePhase. Layout: Auto Layout, frames and constraints versus declarative layout. Navigation: UINavigationController versus NavigationStack. State: explicit updates versus state-driven view updates.

SAY

Key distinction: the delegates are lifecycle integration mechanisms, while SwiftUI is also a whole UI framework. The comparison helps teaching, but they are not one-to-one replacements.

Part 7 · Delegate adaptor

UIApplicationDelegateAdaptor

NPayApp.swift
import SwiftUI
import UIKit

class AppDelegate: NSObject, UIApplicationDelegate {

    func application(
        _ application: UIApplication,
        didFinishLaunchingWithOptions launchOptions:
            [UIApplication.LaunchOptionsKey: Any]?
    ) -> Bool {
        print("Application initialized")
        return true
    }
}

@main
struct NPayApp: App {

    @UIApplicationDelegateAdaptor(AppDelegate.self)
    var appDelegate

    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}
1A plain AppDelegateconforms to UIApplicationDelegate
2@UIApplicationDelegateAdaptorSwiftUI creates it and forwards delegate calls
3The App stays SwiftUIWindowGroup and views as usual
A modern SwiftUI structure, plus UIKit application delegate functionality where it is needed.
SAY

The AppDelegate is an ordinary class conforming to UIApplicationDelegate. The App declares @UIApplicationDelegateAdaptor, and SwiftUI creates that delegate and forwards application delegate calls to it. Everything else stays SwiftUI.

SAY

This is how you keep a modern SwiftUI structure while integrating UIKit application delegate functionality that some system integrations require.
