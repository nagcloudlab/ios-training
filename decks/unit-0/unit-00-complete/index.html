Part 1 · Imperative vs declarative

UIKit style vs SwiftUI style

SwiftUI uses a declarative approach: the UI is a function of its state.

UIKit style
  1. Create a UILabel
  2. Set its text
  3. Update it manually when needed

Imperative: tell the interface what to change.

SwiftUI style
  1. Declare a view
  2. Connect it to state
  3. Change state

Declarative: describe the desired result.
