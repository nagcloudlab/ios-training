Part 5 · URLSession

Fetching the balance

BalanceService.swift
import Foundation

struct BalanceService {
    func fetchBalance() async throws -> Balance {
        let url = URL(string: "https://api.npay.example/balance")!
        let (data, response) = try await URLSession.shared.data(from: url)
        guard let http = response as? HTTPURLResponse,
              (200..<300).contains(http.statusCode) else {
            throw URLError(.badServerResponse)
        }
        return try JSONDecoder().decode(Balance.self, from: data)
    }
}

The URL is fictional; no authentication header yet. Balance is defined in Part 6.

1Create the URL
2Ask URLSessionto perform the request
3Suspend at awaitwhile the operation is pending
4Receivethe response or an error
5Validateany 2xx status
6Decodeinto a Balance (Part 6)
SAY

Six steps: create the URL, ask URLSession to perform the request, suspend at await while it is pending, receive the response or an error, validate the response, and decode it. Validation accepts any status from 200 up to 299, not only 200: a 2xx code means success. Anything else becomes an error the ViewModel can show.

EXPECT

No. The asynchronous task suspends while the networking operation proceeds, as in Lesson 0.5.

Decoding the balance

response.json
{
  "accountId": "123",
  "currency": "INR",
  "balanceMinor": 2500000

Balance.swift
struct Balance: Decodable {
    let accountId: String
    let currency: String
    let balanceMinor: Int64
}

// BalanceService ends with exactly this step:
func decode(_ data: Data) throws -> Balance {
    try JSONDecoder().decode(Balance.self, from: data)
}
balanceMinor is in the smallest currency unit: 2,500,000 paise is ₹25,000. Integer minor units avoid floating-point errors in money.
SAY

The JSON has an account ID, a currency and balanceMinor, the amount in the smallest unit. For INR, 2,500,000 paise is ₹25,000. A Decodable struct, Balance, has matching properties, and JSONDecoder in BalanceService turns the bytes into a Balance. If a key is missing or has the wrong type, decoding throws.

SAY

Integer minor units, or an appropriate decimal type, avoid the floating-point issues that are dangerous in financial calculations.

Part 7 · MVVM · conceptual

A ViewModel in the request path

The view owns it: @State private var model = DashboardViewModel()

DashboardViewModel.swift
@MainActor @Observable
final class DashboardViewModel {
    var balanceText = "—"
    var errorMessage: String?
    private let service = BalanceService()

    func refreshBalance() async {
        do {
            let balance = try await service.fetchBalance()
            balanceText = (Decimal(balance.balanceMinor) / 100)
                .formatted(.currency(code: "INR"))
        } catch { errorMessage = error.localizedDescription }
    }
}
SAY

Click down: the view displays the balance and loading state; the ViewModel coordinates the API call and updates observable state; the service uses URLSession and decodes; the server returns authorized account information.

SAY

DashboardViewModel is @MainActor, so its state changes happen on the main actor, and @Observable, so SwiftUI redraws when balanceText changes. It awaits BalanceService, formats the minor units as rupees for display, and on error stores a message. Formatting is the ViewModel’s job, not the view’s.

Five possible outcomes

Part 9 · Background transfers

What happens when the app is backgrounded?

Normal foreground request

Not automatically guaranteed to continue indefinitely once the app is suspended.

Background URLSession

Uploads and downloads only, handed to the system so they can finish while NPay is suspended or terminated, on the system’s schedule.

It is not a way to keep your own code running, and if the user force-quits NPay from the app switcher, its background transfers are cancelled.
SAY

A normal foreground URLSession request is not guaranteed to continue indefinitely after the app is backgrounded and suspended. For transfers that must survive suspension or even termination by the system, iOS provides background URLSession configurations. They support upload and download tasks only, not ordinary data tasks, and the system schedules them.

SAY

Background URLSession is not a way to run arbitrary code after suspension. And if the user force-quits the app from the app switcher, the system cancels its background transfers. Unit 05, lesson 5.8, builds one; Unit 10, lesson 10.7, covers BackgroundTasks.

SAY

LIVE DEMO / lab script. Full lab.swift: import Foundation, then the excerpt on the slide. It prints ₹25,000.00 (the exact format depends on the locale). Model answer for classify: switch status { case 200..<300: "success: decode the body"; case 401: "sign in again"; case 400..<500: "request problem: don’t retry as-is"; case 500..<600: "server problem: try again later"; default: "unexpected" }, then loop over [200, 204, 401, 404, 500, 503] and print each. Discussion: 204 is a success with no body, so decoding it as a Balance would fail.
