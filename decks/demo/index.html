Does every icon tap create a new OS process?
No. If a process for the app already exists, the system foregrounds it instead of creating a new one.

A recipe book (installed program) is not the same as a working kitchen (running process).

Teaching diagrams are hand-built svg.art. Real images are only for things that must look real:

  • Xcode and Simulator screenshots
  • Instruments traces

Usage pattern

Add animation class to any element. Entrance animations pair with .step; continuous animations run independently.

Composable

Combine: .step .anim-scale .stagger gives you a zoom-in with staggered children. Mix and match freely.
