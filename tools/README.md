# Deck generators

Lessons 0.2–0.10 are generated by Python scripts; Lesson 0.1 is hand-edited HTML.

| File | Purpose |
|---|---|
| `gen02.py` + `post02_text.py` | Lesson 0.2 (gen02 also holds the shared SVG/slide helpers the other generators import) |
| `gen03.py` … `gen10.py` | Lessons 0.3 – 0.10 |
| `build.sh` | Regenerate all of the above: `sh tools/build.sh` |
| `structure.py` | Tag-balance / notes-placement check: `python3 tools/structure.py decks/*/*/index.html decks/demo/index.html` |
| `mkaudit.py` | Writes a browser audit page (every click state: overflow, dead clicks, unused highlights, JS errors). Usage: `python3 tools/mkaudit.py decks/unit-0/lesson-0.5/index.html <outdir>` then open `<outdir>/audit.html` in headless Chrome and read the `data-audit` attribute; the outdir must sit three levels below a `shared/` link (decks use `../../../shared/`). |

Edit a lesson by changing its generator, then run `build.sh`. Never hand-edit a generated `index.html`; the next build overwrites it.

## Shared Unit 00 helpers (in `gen02.py`, above `S = []`)

| Helper | Slide |
|---|---|
| `archmap(focus, lits)` | The one NPay architecture map; `focus` keys turn teal, `lits` moves the teal on clicks |
| `map_slide(...)` | "Where we are": map + Last time / Today |
| `recap_slide(...)` | Map + three recap points |
| `next_slide(...)` | Later plan lessons that build on this one |
| `lab_slide(...)` | Lab: goal, steps, hand-in (or a code window) |
| `qhtml(q)` | Review question text: stem + `.q-code` lines + `.q-opts` A–D |

Don't name a top-level variable `_NPAY_MAP` in a generator (the map helper uses it).
