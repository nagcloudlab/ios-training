# Deck generators

Lessons 0.2–0.10 are generated by Python scripts; Lesson 0.1 is hand-edited HTML.

| File | Purpose |
|---|---|
| `gen02.py` + `post02_text.py` | Lesson 0.2 (gen02 also holds the shared SVG/slide helpers the other generators import) |
| `gen03.py` … `gen10.py` | Lessons 0.3 – 0.10 |
| `gen1_1.py` … `gen1_10.py` | Lessons 1.1–1.10 (Unit 01 generators are named `gen<unit>_<lesson>.py`) |
| `gen2_1.py` … `gen2_12.py` | Lessons 2.1–2.12 (Unit 02; exec `unit2.py`) |
| `unit2.py` | Unit 02 settings (`UNIT_NO`, `UNIT_TITLE`, `UNIT_LESSONS`; name new lessons here as their texts arrive), then exec's `unit1.py`; adds the evidence helpers `console`, `PHONE`, `crop`, `tbl` |
| `sim2_1/` | Lesson 2.1 evidence app: `sh tools/sim2_1/run.sh` builds it, runs each experiment in the iOS Simulator, prints the console and refreshes the screenshots in `decks/unit-2/lesson-2.1/img/` (`crop.swift` trims each to its content; `ta.lproj` holds the Tamil demo string) |
| `sim2_2/` | Lesson 2.2 evidence app with an asset catalog (`Assets.xcassets`, logo drawn by `makelogo.swift`): `sh tools/sim2_2/run.sh` runs each experiment, prints the console and SwiftUI's system-log messages, and refreshes `decks/unit-2/lesson-2.2/img/` |
| `sim2_3/` | Lesson 2.3 evidence app: `sh tools/sim2_3/run.sh` prints types and measured stack sizes (also at Accessibility XL) and refreshes `decks/unit-2/lesson-2.3/img/` |
| `sim2_4/` | Lesson 2.4 evidence app: `sh tools/sim2_4/run.sh` prints HStack types and measured widths (spacing, equal flex, Spacer, layoutPriority) and refreshes `decks/unit-2/lesson-2.4/img/`. Don't attach a measuring modifier to a `Spacer` itself: wrapped, it stops being stack-aware and grows on both axes |
| `sim2_5/` | Lesson 2.5 evidence app: `sh tools/sim2_5/run.sh` prints ZStack types and sizes (ZStack vs VStack, background, overlay, card variants) and refreshes `decks/unit-2/lesson-2.5/img/`. Keep `.zIndex` as the child's last modifier |
| `sim2_6/` | Lesson 2.6 evidence app: `sh tools/sim2_6/run.sh` prints modifier-chain types, a body-evaluation trace and measured sizes (order, frames, frame/padding orders) and refreshes `decks/unit-2/lesson-2.6/img/` |
| `sim2_7/` | Lesson 2.7 evidence app: `sh tools/sim2_7/run.sh` turns simulator accessibility on (SwiftUI only exposes accessibility elements then), activates buttons through them (the real Button action runs; real finger taps can't be scripted here), prints call stacks (demangled), body-vs-action counts, disabled and blocking runs, then turns accessibility off |
| `sim2_8/` | Lesson 2.8 evidence app: `sh tools/sim2_8/run.sh` (accessibility activation as in 2.7) prints @State types, body/state traces, `_printChanges`, the identity reset, and refreshes `decks/unit-2/lesson-2.8/img/` |
| `sim2_9/` | Lesson 2.9 evidence app: `sh tools/sim2_9/run.sh` prints Binding types, the shared-balance trace, the two-sources divergence, clamping and custom bindings, and refreshes `decks/unit-2/lesson-2.9/img/` |
| `sim2_10/` | Lesson 2.10 evidence app: `sh tools/sim2_10/run.sh` prints ForEach types, the flag-then-insert experiment under stable id / index / computed UUID, row-body counts for 1,000 rows (VStack, LazyVStack, List), and refreshes `decks/unit-2/lesson-2.10/img/` |
| `sim2_11/` | Lesson 2.11 evidence app (complete 2.11 code unchanged + a driver): focuses `UITextField`s as a tap would, types with `UIKeyInput.insertText`, pastes, prints onChange/focus/validation results and refreshes `decks/unit-2/lesson-2.11/img/` (real system keyboards in the screenshots) |
| `sim2_12/` | Lesson 2.12 evidence app (complete capstone code unchanged + the 2.11 driver helpers): sends ₹1,500, runs the verification table, prints balances/status from accessibility labels, and refreshes `decks/unit-2/lesson-2.12/img/` ("before" is copied from 2.11's final screen) |
| `unit1.py` | Unit 01 helpers exec'd by each Unit 01 generator: `divider`, the Swift `stack()` picture, `review(QA)`, slide builders (`title_slide`, `outcomes_slide`, `where_slide`, `recap_u1`, `review_divider`, `end_slide`, `write_deck`) and small helpers (`ul`, `card`, `out`, `err`, `TWO`) |
| `build.sh` | Regenerate all of the above: `sh tools/build.sh` |
| `structure.py` | Tag-balance / notes-placement check: `python3 tools/structure.py decks/*/*/index.html decks/demo/index.html` |
| `mkaudit.py` | Writes a browser audit page (every click state: overflow, dead clicks, unused highlights, JS errors). Usage: `python3 tools/mkaudit.py decks/unit-0/lesson-0.5/index.html <outdir>` then open `<outdir>/audit.html` in headless Chrome and read the `data-audit` attribute; the outdir must sit three levels below a `shared/` link (decks use `../../../shared/`). |

Edit a lesson by changing its generator, then run `build.sh`. Never hand-edit a generated `index.html`; the next build overwrites it.

## Shared Unit 00 helpers (in `gen02.py`, above `S = []`)

| Helper | Slide |
|---|---|
| `archmap(focus, lits)` | The one NPay architecture map; `focus` keys turn teal, `lits` moves the teal on clicks |
| `map_slide(...)` | "Where we are": map + Last time / Today |
| `recap_slide(...)` | Map + three recap points |
| `next_slide(...)` | Later plan lessons that build on this one |
| `lab_slide(...)` | Lab: goal, steps, hand-in (or a code window) |
| `qhtml(q)` | Review question text: stem + `.q-code` lines + `.q-opts` A–D |

Don't name a top-level variable `_NPAY_MAP` in a generator (the map helper uses it).
