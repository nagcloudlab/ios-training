Edit a lesson by changing its generator, then run `build.sh`. Never hand-edit a generated `index.html`; the next build overwrites it.

## Shared Unit 00 helpers (in `gen02.py`, above `S = []`)

| Helper | Slide |
|---|---|
| `archmap(focus, lits)` | The one NPay architecture map; `focus` keys turn teal, `lits` moves the teal on clicks |
| `map_slide(...)` | "Where we are": map + Last time / Today |
| `recap_slide(...)` | Map + three recap points |
| `next_slide(...)` | Later plan lessons that build on this one |
| `lab_slide(...)` | Lab: goal, steps, hand-in (or a code window) |
| `qhtml(q)` | Review question text: stem + `.q-code` lines + `.q-opts` A–D |

Don't name a top-level variable `_NPAY_MAP` in a generator (the map helper uses it).
